# SML Miner (Pearl Network Consensus V3)

High-performance Multi-GPU Tensor Core miner for Pearl Network (Consensus V3) optimized for NVIDIA Ampere, Ada Lovelace, and Blackwell GPUs.

## Quick Start
1. Download `sml_miner_v1.0.0_linux_x64.tar.gz` from Releases.
2. Extract: `tar -xzvf sml_miner_v1.0.0_linux_x64.tar.gz`
3. Run: `./run.sh --backend cuda --tc --pool stratum+tcp://prl-ru.kryptex.network:7048 --wallet YOUR_WALLET --worker rig01`
